# Security policy

Do not publish suspected vulnerabilities in a public issue. Use GitHub private vulnerability reporting and include reproduction steps, affected routes, and expected impact.

Supported frontend fixes target the current `main` branch. Report backend, database, authentication, order-pricing, or payment-verification issues in the private security channel of [chaska_backend](https://github.com/BR2225/chaska_backend).

Never include customer data, payment credentials, access tokens, cookies, connection strings, or `.env` contents in a report.
