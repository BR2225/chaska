# DolceVita - Italian Desserts Business PRD

## Problem Statement
Italian dessert (Bomboloni & Tiramisu) business website branded as **Chaska**. Features: Product catalog, online ordering, admin panel, pay-on-delivery + Razorpay.

## What's Been Implemented (April 2026)
- Full product catalog (10 seeded products) with category filtering
- Shopping cart with localStorage persistence + checkout with COD
- **Order tracking page** at /track-order with status timeline
- **Mock email notifications** logged to console on order creation
- Brand name: **Chaska** (renamed from DolceVita)
- Contact form, customer reviews, admin panel (dashboard, products CRUD, orders, contacts)
- JWT auth, admin seeded as admin@example.com / admin123
- Razorpay integration code ready (needs API keys)
